⚠️ TROUBLESHOOTING
────────────────────────────────────────────────────────────────

No API key?
  → Get from: https://makersuite.google.com/app/apikey
  → Set: $env:GOOGLE_API_KEY = "sk-..."

Ingestion fails?
  → Delete: rmdir /s data\vector_db
  → Restart: python scripts/fast_ingest.py

No documents found?
  → Check: (Get-ChildItem data\vector_db -Recurse | Measure-Object -Property Length -Sum).Sum / 1MB
  → Should be: >100 MB
